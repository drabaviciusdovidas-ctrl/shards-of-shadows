# Shards of Shadows

Классовый RPG-сервер Minecraft Java 26.3.

## Как зайти

1. Скачайте лаунчер: **[RPG-Launcher-setup.exe](https://github.com/drabaviciusdovidas-ctrl/shards-of-shadows/releases/latest/download/RPG-Launcher-setup.exe)** и установите.
2. Откройте лаунчер, войдите в аккаунт проекта (или зарегистрируйтесь) и привяжите **лицензионный** Minecraft (вход Microsoft).
3. Нажмите «Играть» — лаунчер сам поставит игру, моды и зайдёт на сервер.

Без лицензии Minecraft зайти нельзя.

Адреса сервера лаунчер берёт из файла `connect.json` в этом репозитории — он обновляется автоматически.
